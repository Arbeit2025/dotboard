# お絵かきボード（dotboard）

16×16 のマスにドット絵を描くための、ブラウザだけで完結する小さなお絵かきツールです。

## 使い方

- **描く**：上のパレット（12色）から色を選び、ボードをクリックまたはドラッグして塗ります。タッチ操作にも対応しています。
- **ぜんぶ消す**：ボードを白紙に戻します。
- **PNGで保存**：描いた絵を 384×384 の PNG 画像としてダウンロードします（ドットがくっきり見えるよう拡大して保存します）。

描画はすべてブラウザ側で行い、サーバーには絵のデータを送りません。保存もブラウザのダウンロード機能を使います。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- マス目は 16×16 固定で、サイズ変更やレイヤー、元に戻す（アンドゥ）機能はありません。
- 描いた絵はページを閉じると消えます。残したいときは PNG で保存してください。
- 消しゴム代わりに白で塗る仕様です。
